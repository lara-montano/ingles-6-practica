💡 How it works

Three pieces, one meaning

A phrasal-prepositional verb is verb + adverb + preposition. The meaning is idiomatic, so learn the whole unit, not the pieces. Tap a verb and watch the machine load all three boxes. (Tres piezas que se aprenden juntas: el significado no es la suma de las partes.)

⭐ The key rule

They don’t split — put the object somewhere

Tap the object, then tap the place where you think it goes. Only one slot works. (Toca el objeto y después la casilla: el objeto va siempre después de las tres piezas.)

💡 Two pieces vs three pieces

The third piece changes the rule

In Unit 2 (Structure 5) some two-word phrasal verbs split, and a pronoun object even has to sit in the middle. Add a third piece and that freedom disappears. (Los de dos piezas pueden separarse; los de tres, nunca.)

Test yourself: if you can say the object in the middle, it is a two-part separable verb. With three parts there is no middle — the object waits at the end.
