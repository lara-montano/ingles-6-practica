Beyond “if”: nine ways to add a condition

Each linker adds a condition with its own flavour of meaning. Tap one to see what it means and how it’s used. (Cada conector añade una condición con un matiz distinto.)

The comma rule

Linker first → comma in the middle. Linker second → no comma.

🌂 The classic trap

in case vs if — before or after?

in case = do it before, as a precaution. if = do it after, as a reaction. Same weather, different logic. («in case» = por si acaso, de antemano.)

👩‍🏫 For the teacher — how this page maps to the manual
  • Explore is Grammar 3's nine linkers (meaning + example + the comma rule), plus the flagship in case vs if "before/after" contrast and the fine distinctions (even if/even though, unless = if not, since & as long as with two meanings, otherwise/suppose).
  • Build is productive: students assemble a sentence by choosing the linker that fits the meaning, then transform sentences with the linker in brackets (exercise D), with validation.
  • Drill merges the quizzes into one graded engine (★ match/choose · ★★ fix the error/complete · ★★★ in case vs if, rewrite, since) with a score and streak.
  • Works offline. Reading/writing only — no audio.
