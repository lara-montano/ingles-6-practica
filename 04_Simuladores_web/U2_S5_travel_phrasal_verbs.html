💡 How it works

Verb + particle = one new meaning

A phrasal verb is a verb plus a particle (off, in, out, up, around…) whose meaning is often not the sum of its parts. Learn each one as a whole unit. Pick a travel phrasal verb from the manual and read it in the machine. (El significado no se deduce de las partes: apréndelos completos.)

🧳 The object slot

Where does the object go?

Tap the green object to pick it up, then tap a slot to drop it there — no dragging, so it works on a phone. Separable verbs accept a noun object in both slots; a pronoun object is forced into the middle; inseparable verbs lock the middle slot. (Toca el objeto y luego la casilla de destino.)

    👩‍🏫 For the teacher — how this page maps to the manual
    • Explore is Structure 5 in three views: the particle machine (the manual's twelve travel phrasal verbs with meaning, example and a separable / inseparable / no-object badge), the object slot (tap-to-place, so separability, the pronoun rule and the locked middle slot of inseparable verbs are physical), and the particle families card, which re-sorts the same list by particle. The special-cases card is the manual's exception box (separable list, pronoun rule, inseparable list, register) and the errors card is its pitfall box.
    • Build is productive: students assemble the verb and the particle for the manual's exercise A sentences, then transform — pronoun placement (exercise B) and formal verb → phrasal verb (exercise C), with validation and a model answer.
    • Drill merges the quizzes into one graded engine (★ meaning and form · ★★ pronoun placement and separability · ★★★ register, inseparable verbs and the set off for trap) with a score and a streak.
    • Works offline. Reading/writing only — no audio.
